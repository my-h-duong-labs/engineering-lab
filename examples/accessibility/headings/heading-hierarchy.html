Heading hierarchy comparison

The same small settings page twice. Both look alike because the styling comes from classes. Only the heading levels differ, so they tell a different story about how the page is organized.

The heading lists below are a learning aid, not a screen reader. They are read from each version's own DOM and show only element levels. Screen readers present headings in their own ways, and some offer heading lists you can jump around.

      Notes

      A jump deeper by more than one level, like Settings straight to a level 3, is something to look at. It is guidance to avoid where possible, not an automatic WCAG failure, and it says nothing about whether the heading text is useful. A page does not need exactly one h1 to be valid HTML either; this example uses one because it gives the page a clear top-level subject.

      Because both versions share this file, this page's own outline includes both of them. In a real page there would be one outline.
