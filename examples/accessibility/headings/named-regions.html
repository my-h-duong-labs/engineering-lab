When a region helps

A named region is worth it for a distinct part of the page that someone may want to jump to, like Recent activity above. It is not worth it for every container. These cards are plain list items: no headings, no regions. Marking up each one would add noise to landmark and heading navigation without helping anyone.

A dialog named by its heading

The dialog title is a visible heading, and aria-labelledby makes it the dialog's name. Its level is h2 here because it sits beside this page's other sections. It would be a different level elsewhere, and a dialog title is not automatically an h1.
